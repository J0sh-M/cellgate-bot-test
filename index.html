Embedded Messaging v2 — CellGate Website Support Enhanced Chat Bot — GitHub Pages Deployment

What This Page Is For

This page hosts the Embedded Messaging widget so the CellGate Website Support Enhanced Chat Bot routing flow can be tested end to end. The chat widget should appear in the bottom-right corner.

Widget Status: Loading...

How to Test

  1. Wait for the chat widget to appear (bottom-right of the page)
  2. Click the widget to open it
  3. The bot should greet you with menu options
  4. Select a department (e.g., Customer Support)
  5. Bot will route you to the appropriate queue
  6. As the rep (with status Available For Messaging), accept the incoming work in Service Console
  7. Continue the conversation as the rep

What to Verify in Salesforce

  1. A new Messaging Session record is created (ID starts with 0M...)
  2. The session routes to the correct queue based on the department selection
  3. The rep can accept and join the same conversation seamlessly
